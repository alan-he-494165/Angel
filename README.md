# Angel

**Auxiliary Neural-quantum-state Guided Energy Landscapes**

ANGEL is a research package for sparse neural quantum state (NQS)-supervised adaptation of pretrained machine-learned interatomic potentials (MLIPs) to noncovalent interaction (NCI) energy landscapes.

The first target is correlation-sensitive weak interaction landscapes, especially pi-pi stacking in aromatic dimers, substituted aromatics, heteroaromatic systems, and DNA base-pair stacking motifs.

## Project Idea

Most practical MLIPs are trained on density functional theory (DFT) or semiempirical quantum chemistry labels. These labels are scalable, but their systematic errors can be chemically meaningful for weak interactions. In pi-stacking and related NCIs, sub-kcal/mol errors can change equilibrium distances, motif rankings, and landscape shapes.

ANGEL studies whether a pretrained MLIP can be adapted more efficiently by using a compact set of NQS-derived correction signals on selected NCI-critical configurations, instead of relabeling broad molecular dynamics trajectories with expensive high-level electronic-structure methods.

## Name

**ANGEL** stands for:

```text
Auxiliary Neural-quantum-state Guided Energy Landscapes
```

The name reflects the role of the NQS solver as a sparse guide for the pretrained MLIP. The NQS is not treated as a universal oracle. It provides high-value correction signals on carefully selected configurations where the base MLIP is most likely to inherit chemically meaningful NCI errors.

## Core Workflow

```text
molecular geometry
-> frozen-core FCI Hamiltonian construction
-> label-free variational NQS solving
-> NQS-derived correction signal
-> sparse fine-tuning of a pretrained MLIP
-> NCI landscape evaluation
```

In this project, "FCI" refers to the frozen-core FCI Hamiltonian representation used to define the electronic problem. The NQS is trained without external FCI energy labels by variationally minimizing the Hamiltonian expectation value.

## Intended Contribution

ANGEL is intended as a protocol for adapting existing MLIPs, not as a claim of a universally superior force field.

The central hypothesis is:

> A pretrained MLIP can be made more accurate for correlation-sensitive NCI landscapes by fine-tuning it on a compact set of configurations whose correction signals are generated by variational NQS solvers on frozen-core FCI Hamiltonians.

## Initial Scientific Scope

Primary targets:

- pi-pi stacking
- aromatic dimers
- substituted benzene dimers
- heteroaromatic stacking
- DNA base-pair stacking motifs

Secondary targets:

- pi-H interactions
- mixed dispersion/electrostatic NCIs
- selected S66x8 dispersion and mixed complexes

Out of scope for the first version:

- universal biomolecular force fields
- full protein-ligand simulation
- all classes of NCI
- periodic organic crystals as a main benchmark
- claims that NQS is always more accurate or cheaper than CCSD(T)
- claims that the NQS is trained from exact FCI reference labels

## Baseline Plan

The preferred first baseline is a pretrained organic MLIP such as MACE-OFF.

The preferred first adaptation strategy is a frozen-base delta-correction model:

```text
E_final = E_base + Delta_E_NQS
```

This keeps the pretrained MLIP fixed and trains a small correction head on sparse NQS-derived interaction-energy signals. The goal is to reduce catastrophic forgetting and make small-data behavior easier to analyze.

## Evaluation Focus

ANGEL should be evaluated on landscape-level behavior, not only pointwise energy error.

Important metrics include:

- interaction energy MAE/RMSE
- binding energy error
- equilibrium distance error
- motif ranking accuracy
- curve-shape error along separation scans
- sliding and rotation landscape error
- long-range tail behavior
- compressed-region repulsion behavior
- force projection error, if force-related signals are available
- catastrophic forgetting on general organic conformations

Useful comparisons include:

- base MLIP without fine-tuning
- MD trajectory fine-tuning with low-level labels
- DFT-level fine-tuning on the same configurations
- NQS-supervised fine-tuning on the same configurations
- random NQS selection versus active NQS selection
- frozen-base delta head versus fuller fine-tuning

The strongest protocol test is:

> Same configurations, different supervision signals.

This isolates whether improvement comes from NQS-derived variational wavefunction information rather than from better sampling alone.
